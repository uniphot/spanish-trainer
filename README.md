# A fondo — a research-based Spanish trainer

A self-contained website for learning Spanish on your own, built around what second-language research says works: spaced retrieval, balance across Nation’s four strands, processing instruction, interleaving, metacognitive listening, high-variability perception training, fluency work and hint-first corrective feedback. The in-app **Why it works** page explains each principle with references.

## Run it

```bash
python3 serve.py
```

This opens `http://localhost:8770`. Use **Chrome, Edge or Safari**: speech recognition (speaking exercises) only works in those browsers, and only over `localhost`/https, so open the app through the server rather than double-clicking `index.html`. No install or build step; the only dependency is Python 3, which macOS already has.

### On your phone

The app is published on GitHub Pages by `.github/workflows/pages.yml` on every push to `main`. The same workflow runs every 3 hours to rebuild `news.json` and `listen.json`, because Pages can't run `serve.py`. Open the Pages address in the browser and add it to the Home Screen:
- **iPhone (Safari):** Share → Add to Home Screen. Turn **“Open as Web App” off** if you want the speaking exercises: iOS gives no speech recognition to Home Screen web apps.
- **Android (Chrome):** menu → Add to Home screen / Install app.

Once a page has been opened, the app works offline. Your progress is stored separately on each device and browser. To move it between devices, use Ajustes → Your data → Export backup, then Import backup on the other device.

For better audio on macOS, add a high-quality Spanish voice in System Settings → Accessibility → Spoken Content → System voice → Manage voices (e.g. Mónica, Paulina or Jorge, "Premium/Enhanced"), then choose it in **Ajustes**.

## What’s inside

| Module | What it does |
|---|---|
| **Nivel** (level test) | 70-item yes/no vocabulary-size test with pseudowords (guessing-corrected) → computer-adaptive test (IRT, EAP estimate) over grammar, vocabulary, reading, listening → CEFR can-do self-assessment for speaking/writing. Sets your level per skill. |
| **Gramática** | 49 topics A1–C1, 933 hand-written items (fill-in, multiple choice, find-and-fix), each topic: explanation → structured-input “interpret first” activities → practice with instant explanations. Mixed practice and contrast drills (interleaving), an unlimited conjugation trainer (378 verbs × 15 tenses, generated by a rule-based engine), and an accent trainer (stress perception + tilde rules). |
| **Escuchar** | *Escucha real*: new episodes and videos from 21 mostly Mexican shows, sorted into three difficulty tiers and picked for your level, with a player built for practice (0.75× speed, last-6-seconds repeat, Spanish subtitles, hours counted). Shows with timed transcripts add line-by-line reading and dictation on the real voice. *Así suena México*: lessons on connected speech, reductions, fillers and place names, and 9 everyday scenes. Also 16 graded texts through the metacognitive listening cycle, multi-voice dialogues, dictation with word-level diff and a numbers/prices/times drill. |
| **Hablar** | 13 pronunciation units (minimal-pair ear training with rotating voices, then recorded production checked by speech recognition), shadowing with build-up mode, Nation’s 4/3/2 fluency technique with words-per-minute per round, 8 guided role-plays, and an optional AI conversation partner. |
| **Escribir** | 17 graded tasks with live requirement checklists, analytics (tenses used, connectors, lexical variety, repetitions), a checker with three layers (built-in learner-error rules, LanguageTool, optional AI tutor), hint-first feedback and saved drafts; daily journal, 10-minute quick-writes, dictogloss. |
| **Noticias** | A daily digest of real Mexican news (El Universal, La Jornada, El Financiero, Expansión, Chilango, México Desconocido, BBC Mundo), chosen from your interests. Tap any word for verb analysis, Mexican usage and dictionary links, save words or sentences as cards, listen with a Mexican voice, then retell the article in writing (checked) or out loud. Plus a 74-entry *Español de México* glossary. |
| **Repaso** | One FSRS spaced-repetition queue fed by everything: a 339-word core vocabulary deck (cloze cards in context), grammar items you missed, conjugation slips, dictation sentences, and corrections from your own writing and speaking. |
| **Hoy / Progreso** | Daily plan balancing the four strands, streaks, minutes per strand, review forecast, grammar mastery, cross-module error profile, weekly reflection and journal. |

## Optional online features

- **News digest**: `serve.py` fetches a fixed list of Mexican RSS feeds (see `news.py`) and caches them for 30 minutes. On the published site, the app reads `news.json` instead; the publish workflow regenerates it every 3 hours.
- **Real listening**: `listen.py` does the same for podcasts and YouTube channels (`/api/listen`, `listen.json`). It keeps only titles and links: audio streams from each show’s host, video plays in YouTube’s embedded player, and the browser reads transcripts directly from the podcast host.

- **LanguageTool** (on by default, toggle in Ajustes): when you press *Check my text*, the text is sent to `api.languagetool.org` (free tier, 20 checks/minute). The built-in rules work offline.
- **AI tutor**: paste your own Anthropic API key in Ajustes to unlock detailed writing feedback with a native-like reformulation, the conversation partner, feedback on 4/3/2 monologues, “Ask why” on exercises and AI-generated grammar items. The key stays in your browser and requests go directly to the Anthropic API (default model `claude-opus-5-5`; Sonnet 5.5 and Haiku 5.5 are selectable).

## Accents

A missing or wrong written accent is accepted and shown as an *accent note*, never counted as a mistake — except in the accent topic and accent trainer, whose whole point is the tilde. Settings → Strict accents turns this off.

## Your data

Everything is stored in your browser’s `localStorage`. Use **Ajustes → Export backup** to move progress between browsers or devices.

## Development

```
index.html, css/app.css, serve.py
js/main.js                 router, navigation, strand timer
js/core/                   store, FSRS scheduler, speech (TTS/STT/recording), phonology,
                           conjugator, learner model & daily plan, analyzer, checker, AI client
js/views/                  one module per section
js/data/                   grammar topics, deck, placement items, listening, speaking, writing
tests/                     node tests (conjugator, phonology, FSRS, checker false positives)
```

Run the tests with `npm test` (Node 18+).
